# K-Means Clustering on Iris Dataset

This project implements K-Means clustering on the Iris dataset using Streamlit for an interactive web application. The app allows users to visualize clusters, analyze cluster quality, and explore the dataset.

## Features

- Load and visualize the Iris dataset.
- Perform K-Means clustering with customizable number of clusters (k).
- Visualize clusters in 2D and 3D.
- Display a confusion matrix comparing predicted clusters with true labels.
- Evaluate cluster quality using silhouette scores and other metrics.
- Implement the Elbow Method to determine the optimal number of clusters.
